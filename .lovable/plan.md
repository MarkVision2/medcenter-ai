## Что не так сейчас

**Первый экран:** 3 крупных блока подряд (синяя плашка → чёрный заголовок → ещё одна синяя плашка → кнопка). Глаз не понимает, что главное. Нет «лица» бренда и доверия. Нет якоря (кому это).

**По сайту в целом:**
- Разнобой в заголовках: где-то `text-2xl`, где-то `text-3xl`, где-то `font-extrabold uppercase`, где-то `font-bold` — нет ритма.
- Карточки оформлены по-разному: `border-2 border-destructive`, `border bg-card`, `bg-accent-soft`, `bg-ink-deep` — каждый блок «сам по себе».
- Отступы между секциями одинаковые (`py-12`), нет разделения смысловых групп.
- Эмодзи местами «детские» (🤷‍♂️ 🐺 🛣️ 👇) — конфликтуют с медицинским тоном.
- Некоторые кнопки CTA в «тёмных рамках» (`bg-ink-deep`), некоторые без — непоследовательно.
- Footer слишком сухой по сравнению с агрессивным телом.

## Что сделаю

### 1. Первый экран (HERO) — переработка

Структура:
```text
┌─────────────────────────────┐
│ маленький pill-бейдж        │  ← "Для владельцев медцентров"
│ (синий, компактный)         │
├─────────────────────────────┤
│ ОГРОМНЫЙ ЗАГОЛОВОК          │  ← главный оффер
│ +10 000 000 ₸ за 2 недели   │  ← цифра-якорь
│ для медицинского центра     │
├─────────────────────────────┤
│ короткий подзаголовок       │  ← одна строка пользы
├─────────────────────────────┤
│ [фото Юрия 80×80] Юрий N.   │  ← доверие
│                  автор сис. │
├─────────────────────────────┤
│ [ОРАНЖЕВАЯ КНОПКА CTA]      │
│ ⏱ диагностика за 9 900 ₸    │
└─────────────────────────────┘
```

Ключевое:
- Заменить «двойную синюю плашку» на компактный pill-бейдж сверху + один большой заголовок с цифровым якорем (+10 млн ₸ — реальный кейс из блока 5).
- Добавить мини-карточку автора с фото Юрия прямо в hero — снимает «холодность» и даёт доверие сразу.
- Одна оранжевая CTA с микрокопией снизу («без обязательств», «ответ за 5 минут»).
- Хелпер-строка скролла («↓ как это работает») вместо большого 👇.

### 2. Единая система типографики

Ввести 3 уровня заголовков и применить везде:
- **H1** (только hero): `text-3xl sm:text-5xl font-black leading-[1.05]`
- **H2** (секции): `text-2xl sm:text-3xl font-extrabold leading-tight`
- **H3** (подзаголовки в карточках): `text-lg sm:text-xl font-bold`

Тело: `text-base sm:text-lg leading-relaxed`. Microcopy: `text-sm text-muted-foreground`.

Убрать произвольные `font-black uppercase` в случайных местах.

### 3. Единая система карточек

Три типа, и только они:
- **Card-default** — белая с тонкой границей и мягкой тенью (для контента: кейс, список «что получите»).
- **Card-accent** — `bg-accent-soft` с цветным левым бордюром (для подсказок, ограничений, P.S.).
- **Card-dark** — `bg-ink-deep` белый текст + жёлтый highlight (только для денежных результатов и финальной CTA — максимум 2 раза за весь лендинг).

Сейчас `bg-ink-deep` используется 3 раза (результат, CTA-13, CTA-15) — оставлю в результате и финальной CTA-15, в блоке 13 уберу обводку.

### 4. Ритм отступов

Группировать блоки смыслово:
- Hero (1) → больше воздуха снизу `pb-16`
- Боль (2) + Переход (3) → одна группа, без `tone="muted"` на переходе
- Обо мне (4) + Кейс (5) + Результат (6) → одна группа доверия
- Скепсис (7) + Суть (8) → объединить в один блок (сейчас почти дубль)
- Что получите (9) + Уникальность (10) + Ограничение (11) → группа оффера
- Две дороги (12) + CTA (13) → дожим
- P.S. (14) + Финал (15) → закрытие

Между группами `py-16`, внутри группы `py-10`. Переменный фон `default → muted → default` ритмично, не каждый блок.

### 5. Чистка визуального шума

- Убрать эмодзи 🤷‍♂️ 🐺 🛣️ из «двух дорог» — заменить иконками `lucide-react` (`TrendingDown` / `TrendingUp`) в круглых бейджах. Сохраняем красный/зелёный, но без «колхоза».
- Большой 👇 заменить на `ArrowDown` иконку или вовсе убрать.
- В блоке «боли» иконку `Square` заменить на закрашенный кружок-маркер (`•` стиль), потому что `Square` смотрится как пустой чекбокс и сбивает с толку.
- В кейсе (блок 5) выделить «+10 000 000 ₸» как отдельный визуальный якорь сверху карточки, а не внутри жёлтой подплашки в конце.

### 6. Финальный CTA-блок и footer

- Блок 13 «Время действовать» — упростить: убрать тёмную обводку вокруг кнопки (она создаёт впечатление «отдельного баннера»). Кнопка живёт прямо на белом, баннер сверху.

- Sticky-кнопка WhatsApp снизу экрана на мобильном (после скролла за hero) — высокий конверсионный приём, не ломает контент.
