## 3. Почему лид «не падает в CRM»

Проверка показала:
- В таблице `diagnostic_leads` последняя заявка от 05.05 03:36 **сохранилась корректно** (Aiva Clinic, cta_id=1).
- Edge-функция отработала без ошибок (в логах только `booted/shutdown`, ошибок нет).
- UTM-поля пустые (`utm_source = NULL`) — потому что пользователь заходил на превью без UTM-меток в URL. Это нормально для тестов; на проде с рекламы метки придут.
- Секреты `META_PIXEL_ID`, `META_CAPI_ACCESS_TOKEN`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` присутствуют.

Скорее всего «не падает в CRM» = «не приходит в Telegram в нужном виде». После пункта 2 (новый формат) проверим живой отправкой. Если после теста сообщение всё равно не приходит — посмотрим Telegram API ответ в логах функции (добавим `console.log` ответа Telegram).
