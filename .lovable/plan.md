## Цель
Привести лендинг в порядок: убрать чёрные блоки, всё центрировать, тексты не трогать.

## Изменения в `src/pages/Index.tsx`

### 1. Убрать чёрный цвет
- Заменить `bg-foreground` (чёрная карточка с ценой) → `bg-banner` (синий бренд).
- Убрать обёртки `bg-ink-deep` вокруг CTA-кнопок — оранжевая кнопка остаётся самостоятельно на белом/нейтральном фоне.
- Текст внутри бывших чёрных блоков перевести на `text-banner-foreground` (жёлтый) для контраста на синем.

### 2. Глобальное центрирование
- Ко всем `h2`, `h3` и параграфам секций добавить `text-center`.
- Чек-листы / списки буллетов обернуть в `mx-auto max-w-md` — сам блок по центру, пункты внутри остаются с выравниванием по левому краю (так читабельнее).
- В секции "Обо мне" убрать классы `sm:text-left` / `sm:items-start`, чтобы и на десктопе всё оставалось по центру.
- Убедиться, что у flex-контейнеров стоит `items-center`.

### 3. Hero (первый экран)
- Поднять размер `h1` на мобиле до `text-2xl` для нормальной иерархии над баннерами.
- Все элементы Hero уже идут по центру — оставить как есть.

## Что НЕ меняю
- Тексты — ни одной буквы.
- Структуру секций и порядок блоков.
- Брендовые цвета (`bg-banner`, `cta-orange`, `whatsapp`).
- Компоненты `Banner`, `WhatsAppButton`, `Section` — правки только на уровне страницы.

## Результат
- Ноль чёрных блоков.
- Всё содержимое выровнено по центру по всей странице.
- Единый визуальный ритм: синие баннеры + оранжевые CTA на светлом фоне.
