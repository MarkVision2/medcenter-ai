# Лендинг "Врач на миллион" — план реализации

## Цель
Одностраничный лендинг для владельцев медцентров, ведущий на диагностику через WhatsApp.

## Стиль и UX
- Светлый медицинский стиль: белый фон (#FFFFFF), чёрный текст (#111), мягкий бирюзово-зелёный акцент (медицинский, не яркий)
- Mobile-first от 375px, ширина контента 100%, отступы 16–20px
- Body 16–18px, заголовки 22–28px (на десктопе крупнее), межстрочный 1.5
- Кнопки высотой 52–56px, скруглённые, с иконкой WhatsApp
- Минимум графики: только тонкие разделители, чек-маркеры и иконка WhatsApp
- Лёгкие плавные появления секций при скролле (ненавязчиво)

## WhatsApp интеграция
- Все CTA-кнопки ведут на `https://wa.me/77472842595?text=...` с заранее заготовленным текстом ("Здравствуйте, Юрий! Хочу записаться на диагностику по системе Врач на миллион")
- Открывается в новой вкладке

## Структура (15 блоков)

1. **Hero** — плашка "Проверенная методика для владельцев медцентров", главный заголовок про поиск 2-х владельцев, подзаголовок про доход 300–600 тыс/день, первичная CTA-кнопка WhatsApp
2. **Боль** — заголовок "Вы устали…" + список из 6 пунктов с минималистичными маркерами
3. **Переход** — короткий блок с призывом записаться на диагностику
4. **Обо мне (Юрий)** — плейсхолдер под фото (круглая рамка, серый фон, подпись "Фото"), текст справа/снизу
5. **Кейс Астана** — выделенная карточка со светло-серым фоном: ситуация → действия → результат (+10 млн тг, 107 пациентов)
6. **Результат 60 млн** — крупная цифра-акцент на всю ширину
7. **Скепсис "В чём подвох?"** — текстовый блок с честным ответом
8. **Суть** — заголовок капсом + пояснение про системный подход
9. **Что получите** — карточка-список из 4 пунктов с ценностями, итоговая сумма ценности и стоимость диагностики **9 900 тг** крупно
10. **Уникальность** — короткий текст про "дырявое ведро"
11. **Ограничение** — выделенная строка: "Максимум 2 исследования в неделю. Только одна клиника в городе"
12. **Две дороги** — две колонки (на мобильном — друг под другом): "Первая дорога" (серая, нейтральная) vs "Вторая дорога" (акцентная, для волков)
13. **CTA "Время действовать"** — крупная кнопка WhatsApp
14. **Дожим** — короткая фраза про конкурентов
15. **Финал** — вопрос "В какой категории хотите быть вы?" + финальная CTA-кнопка
