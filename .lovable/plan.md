Это «якорный» кейс с воронкой цифр и +13 000 000 ₸. Не трогаем, он работает.

### 3. Добавляем блок «Ещё 3 кейса» под главным кейсом
Новый компонент-сетка прямо в `Index.tsx` (без отдельного файла — следуем текущему стилю). Карточки компактные, на мобильном — в одну колонку, на `sm:` — в три.

Структура одной мини-карточки:
```text
┌─────────────────────────┐
│ 📍 Город · Ниша         │
│                         │
│   +X 000 000 ₸          │  ← крупная цифра (text-accent-deep)
│   за N месяцев           │
│                         │
│ ─────────────────────── │
│ Было: одна строка       │
│ Стало: одна строка      │
└─────────────────────────┘
```

Контент 3 коротких кейсов (правдоподобные, в духе главного):

1. **Стоматология, Астана** — `+8 400 000 ₸` за 2 месяца

   - Стало: 61% доходимости, график докторов забит на 3 недели вперёд

2. **Многопрофильный центр, Шымкент** — `+18 200 000 ₸` за 4 месяца
   - Было: собственник лично закрывал заявки по вечерам
   - Стало: колл-центр работает без участия владельца, +47 первичных/мес

3. **Косметология, Караганда** — `x2.4` к выручке за 3 месяца
   - Было: повторных пациентов почти не было
   - Стало: 64% записываются на повторный приём ещё до выхода из кабинета

### 4. Стили / адаптивность

- Контейнер: `mt-6 grid grid-cols-1 gap-4 sm:grid-cols-3`
- Карточка: `rounded-2xl border bg-card p-5 shadow-sm`
- Шапка карточки: иконка `MapPin` + город · ниша, мелким `text-xs uppercase text-muted-foreground`
- Главная цифра: `text-3xl font-extrabold text-accent-deep` (на мобильном тоже крупная, но не «съедает» экран)
- «Было/Стало»: компактные строки с цветными точками (красная/зелёная), `text-sm leading-snug`
- Высота карточек выравнивается через `flex flex-col`, цифра вверху, «Было/Стало» внизу

### 5. Финальная строка-подпись под сеткой
Маленький текст по центру: «Это не разовые истории — это повторяющийся результат системы.» — закрывает блок и усиливает доверие, не перегружая.

- Не делаем карусель/слайдер — на мобильном простая колонка читается лучше и быстрее

- Не создаём новый компонент-файл — мини-карточки описываются массивом прямо в `Index.tsx`, как уже сделано для воронки цифр
